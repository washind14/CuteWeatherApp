# 🌤️ CuteWeatherApp

![GitHub license](https://img.shields.io/badge/license-MIT-blue.svg)

## 📌 Overview
CuteWeatherApp is a lightweight and aesthetically pleasing weather application that provides real-time weather updates based on user input. Designed with a clean and modern UI, this app delivers a delightful user experience while displaying essential weather details.

## ✨ Features
- Search for weather updates by city name
- Displays temperature, weather conditions, humidity, and wind speed
- Responsive and user-friendly design
- Dynamic weather icons based on conditions

## 🛠️ Technologies Used
- **HTML5**: Markup structure
- **CSS3**: Styling and animations
- **JavaScript (ES6+)**: Core functionality
- **OpenWeather API**: Fetch real-time weather data

## 🚀 Getting Started
### Prerequisites
- A web browser (Chrome, Firefox, Edge, etc.)
- A free API key from [OpenWeather](https://openweathermap.org/api)

### Installation
1. Clone the repository:
   ```sh
   git clone https://github.com/washind14/CuteWeatherApp.git
   ```
2. Navigate to the project folder:
   ```sh
   cd CuteWeatherApp
   ```
3. Open `index.html` in your browser.

## 🔥 API Usage
This app fetches weather data using the OpenWeather API:
- Base URL: `https://api.openweathermap.org/data/2.5/weather?q={city name}&appid={API key}`
- Response includes temperature, weather conditions, humidity, and wind speed.
